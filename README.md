# Sui Nexus Application

A decentralized application built on the Sui blockchain.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`

2. Set the `GEMINI_API_KEY` in `.env.local` to your Gemini API key

3. Run the app:
   `npm run dev`

## Features

- Sui blockchain integration
- Move smart contracts
- DAO curation
- Ledger explorer
- Sui terminal

## Network

Currently configured to run on **Sui Devnet**.
